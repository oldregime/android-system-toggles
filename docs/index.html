System Toggles

A lightweight display & network utility for Android
🔄

Display Refresh Rate

Instantly switch between Smooth 120Hz and Standard 60Hz. Save battery on standby and maximize performance on demand.

📶

5G / LTE Preferred Network

Toggle 5G capabilities off to force LTE-only. Saves substantial standby battery when 5G signal search is redundant.
